# Streamlining IT Procurement – Automating Standard Laptop Orders with Flow Designer

## Project Overview

This project focuses on streamlining IT procurement by automating standard laptop orders using ServiceNow Flow Designer.

The solution automates the laptop ordering process through Service Catalog and Flow Designer, helping to reduce manual activities and improve the IT procurement workflow.

## Platform Used

- ServiceNow
- Service Catalog
- Flow Designer

## Project Type

IT Service Management (ITSM) Process Automation

## Objective

The main objective of this project is to automate the process of standard laptop orders and create an efficient IT procurement workflow using ServiceNow Flow Designer.

## Key Features

- Standard laptop request through Service Catalog
- Automated request processing
- Flow Designer based workflow automation
- IT procurement process streamlining
- Reduced manual effort
- Improved request tracking and processing

## Project Scope

The project covers the automation of standard laptop ordering within the ServiceNow platform using Service Catalog and Flow Designer.
